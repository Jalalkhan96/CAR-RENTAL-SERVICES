# CAR-RENTAL-SERVICES

Design documentation for a car rental system website — UML analysis and design diagrams produced for a Software Design & Architecture (SDA) project.

## What it is

This repository holds the design document for a **Car Rental System Website**. It is a documentation-only repo: the deliverable is the PDF below, which models the system before implementation. There is no application source code in this repo.

## Contents

```
CAR RENTAL SERVICE (SDA).pdf   Design document (4 pages)
LICENSE                         MIT license
README.md                       This file
```

The PDF contains:

- **Use case diagram** — the actors and main use cases of the car rental website
- **Fully dressed use case diagram** — the expanded, detailed version of the main use case
- **System sequence diagram** — message flow between the user and the system for the core scenario
- **Class diagram** — the system's classes and their relationships

## Run it

Nothing to build or run — open the PDF in any viewer:

```bash
# from a clone of this repo
xdg-open "CAR RENTAL SERVICE (SDA).pdf"   # Linux
open "CAR RENTAL SERVICE (SDA).pdf"       # macOS
```

## Tech

- UML modelling (use case, sequence and class diagrams), delivered as a PDF document
